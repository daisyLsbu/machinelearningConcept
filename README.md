How to start:
Pre requisite: 
Python
vscode extention - jupyter by microsoft or any IDE

You can either checkout whole project or download just the notebook you would like to use.
to checkout use this: 
git clone https://github.com/daisyLsbu/<reponame>.git
cd <reponame>

if you want to set the environment: optional
python -m venv venv
venv\Scripts\activate
pip install ipykernel jupyter
python -m pip install --upgrade pip

requirements.txt has all the dependencies, it can be installed with 
pip install -r reuirements.txt

data folder has all the files required in any of the code.
